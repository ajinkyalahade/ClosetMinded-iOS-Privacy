Common questions

Do I need an account?
No. Everything is on your iPhone.

Will my wardrobe move to a new iPhone?
Yes, if you set up the new phone from a backup of the old one (iCloud Backup, a computer, or Quick Start). ClosetMinded doesn't sync between devices, so two phones in use at the same time each keep their own wardrobe.

Tagging got a garment wrong.
Tap the item and correct it. The free on-device option recognises broad categories only. For fabric and cut, choose a Claude option in Settings, which needs your own Anthropic API key.

The "better" on-device option is downloading.
It's a one-time download of about 2 GB, best done on Wi-Fi. Basic tagging keeps working while it downloads.

There's no weather.
Allow location for ClosetMinded in iOS Settings → Apps → ClosetMinded → Location. Approximate is enough. Weather also needs an internet connection.

How do I delete everything?
Settings → Erase everything, or delete the app.

Sending a crash report
Settings → Export crash reports, then attach the file to an email. Nothing is sent automatically.
